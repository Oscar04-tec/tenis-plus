Fuentes de datos.

GitHub Actions publica automáticamente una cartelera estática usando una clave privada. Esta web no consulta directamente la API ni usa un servidor Node.

Conexión automática

API
Live Tennis API · plan GRATISATP, WTA, Challenger, ITF y Junior; calendario, marcadores y datos de jugadores según cobertura. Sin cuotas ni probabilidades.
SIN CONECTAR

Obtén una clave gratuita sin tarjeta; guárdala en el secreto LIVETENNISAPI_KEY de tu repositorio GitHub. Ejecuta el flujo en la pestaña Actions. La clave nunca se incluye en esta página.

Crear clave gratis ↗
El plan gratuito tiene 100 consultas al día; Actions refresca hasta tres veces diarias según programación, con retrasos posibles. No incluye cuotas, H2H completo ni probabilidades propias.

Cargar partidos sin API

No se incorporan ejemplos históricos a la cartelera diaria. Si Actions aún no se ejecutó, la jornada aparecerá vacía. También puedes importar encuentros contrastados.

Respaldo de tu historial

Las apuestas y evaluaciones se guardan en el almacenamiento local de este navegador. Exporta respaldos para conservarlos o migrarlos a otro dispositivo.

!
Limitaciones importantes

El calendario depende de la cobertura de la API. Horarios sin zona confirmada se muestran como provisionales. Cuotas no asociadas a una casa o vigencia verificable deben confirmarse antes de registrar una apuesta. La liquidación final depende de las reglas de la casa.
